# BorHor
«BorHor» — лёгкая и удобная утилита для создания скриншотов произвольной области экрана. Программа сочетает минималистичный интерфейс с функциональностью: позволяет быстро захватить нужную часть экрана, улучшить качество изображения и скопировать его в буфер обмена для дальнейшего использования.
